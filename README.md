# Cookie Eater

A lightweight, local browser extension to automatically clean up your browsing experience by wiping out cookie consent popups and tracking prompts.

## 📥 Download & Installation

1. **Download** the raw source files or the `.zip` archive from this repository.
2. **Extract** the folder contents to a permanent location on your computer.
3. Open Google Chrome and navigate to `chrome://extensions/`.
4. Enable **Developer mode** using the toggle switch in the top-right corner.
5. Click **Load unpacked** in the top-left corner.
6. Select your extracted project folder containing the script files.
